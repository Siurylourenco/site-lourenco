# 🌐 Site Lourcode https://lourcode.com.br/ – Website Profissional

## 📌 Sobre o Projeto

Este é o **meu primeiro site profissional**, desenvolvido para apresentação institucional e presença online.  
O projeto foi criado com **HTML, CSS e JavaScript**, com foco em organização de código, experiência do usuário e boas práticas básicas de SEO.

Além do desenvolvimento, o site foi **publicado em hospedagem profissional (HostGator)** e teve **configurações de SEO realizadas no Google Search Console**, em um cenário real de entrega para cliente.

Este projeto representa um marco importante no meu crescimento como desenvolvedora web.

## 🧠 Tecnologias e Ferramentas Utilizadas

| Tecnologia / Ferramenta | Finalidade |
|-------------------------|------------|
| `HTML5` | Estrutura semântica do site |
| `CSS3` | Estilização e layout |
| `JavaScript` | Interatividade |
| `Git & GitHub` | Versionamento de código |
| `HostGator` | Hospedagem do site |
| `Google Search Console` | Monitoramento e SEO |
| `DNS / Domínio` | Configuração de apontamento |

## 🌍 Hospedagem e Deploy

O site foi publicado em **hospedagem compartilhada da HostGator**, incluindo:

- Upload manual dos arquivos via painel/FTP;
- Configuração de domínio e apontamento DNS;
- Estrutura organizada para produção;
- Testes pós-publicação.

Esse processo me permitiu entender na prática como funciona a publicação de um site fora de plataformas automáticas (como Vercel ou Netlify).

## 🔍 SEO e Google Search Console

Foram realizadas configurações iniciais de SEO, incluindo:

- Cadastro do site no **Google Search Console**;
- Envio do site para indexação;
- Verificação de domínio;
- Ajustes básicos para melhor leitura pelos motores de busca;
- Monitoramento de status e cobertura.

Essas etapas fazem parte do processo real de entrega de um site profissional.

## ✨ Funcionalidades do Site

- Estrutura HTML semântica;
- Layout organizado e limpo;
- Navegação simples entre páginas;
- Página de agradecimento (`obrigado.html`);
- Estilos personalizados em CSS;
- Scripts JavaScript para interações básicas.
